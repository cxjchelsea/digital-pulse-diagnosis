# 系统需求规格说明书

版本：0.1.0  
适用阶段：P0软件仿真基线，兼容未来P1硬件

## 1. 系统边界

系统由采集硬件、信号处理和分析软件三层组成。P0使用设备模拟器替代真实采集硬件，但协议和数据字段保持一致。

## 2. 优先级

- 必须：P0退出前必须满足；
- 应当：不阻塞P0，但进入P1前必须满足；
- 可选：后续研究能力。

## 3. 采集硬件层需求

| ID | 优先级 | 需求 | P0验证 |
|---|---|---|---|
| COL-F-001 | 必须 | 设备应按配置的固定采样率产生同步脉搏、载荷和参考通道 | 模拟器样本数量与时间戳测试 |
| COL-F-002 | 必须 | 每个样本应含帧序号、样本序号和单调设备时间戳 | 协议回环测试 |
| COL-F-003 | 必须 | 每个样本应含电机位置、目标载荷、设备状态和故障位 | 字段完整性测试 |
| COL-F-004 | 必须 | 正式采集使用带CRC的二进制帧 | 单比特错误测试 |
| COL-F-005 | 应当 | 设备应支持接触、稳定、采集、换挡、退回和故障状态 | 状态机场景测试 |
| COL-S-001 | 必须 | 安全退回不得依赖分析软件 | P1硬件验证，P0验证状态语义 |
| COL-S-002 | 必须 | 未知协议版本和非法命令不得静默执行 | 异常协议测试 |

## 4. 信号处理层需求

| ID | 优先级 | 需求 | 验证 |
|---|---|---|---|
| SIG-F-001 | 必须 | 检测CRC错误、长度错误和未知协议版本 | 单元测试 |
| SIG-F-002 | 必须 | 检测序号不连续、时间戳回退和数据缺失 | 集成测试 |
| SIG-F-003 | 必须 | 原始帧不可被滤波结果覆盖 | 文件结构检查 |
| SIG-F-004 | 必须 | 能处理基线漂移并检测心搏峰 | 合成黄金信号 |
| SIG-F-005 | 必须 | 输出质量标签、评分和失败原因 | 正常、常量、削顶样本测试 |
| SIG-F-006 | 必须 | 质量不足的数据不得进入正式分析结果 | 分析门控测试 |
| SIG-P-001 | 应当 | 250 Hz单通道数据的处理速度应高于实时速度 | 性能测试 |

## 5. 分析软件层需求

| ID | 优先级 | 需求 | 验证 |
|---|---|---|---|
| APP-F-001 | 必须 | 支持模拟会话生成、保存和重放 | 端到端测试 |
| APP-F-002 | 必须 | 会话记录配置、版本、状态和完整性摘要 | Schema验证 |
| APP-F-003 | 必须 | 仅对质量合格窗口计算心率等正式参数 | 门控测试 |
| APP-F-004 | 应当 | 提供实时波形、载荷、状态和错误显示 | P0 UI验收 |
| APP-F-005 | 应当 | 支持原始与处理波形对照 | P0 UI验收 |
| APP-D-001 | 必须 | 人体数据不得提交公开仓库 | 仓库与gitignore检查 |
| APP-D-002 | 必须 | 派生结果应记录输入、代码和参数版本 | Manifest检查 |

## 6. P0退出条件

- 协议、模拟器和信号处理单元测试全部通过；
- 相同种子生成完全相同的数据；
- 单比特帧错误能被CRC识别；
- 合成75 bpm信号的心率误差小于1 bpm；
- 常量信号被拒绝；
- 模拟器可生成完整多载荷会话；
- 需求、协议、数据和测试能够相互追踪。

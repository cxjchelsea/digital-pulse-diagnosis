# D3被控对象与传感观测模型设计

版本：0.1.0  
状态：D3-B实现，等待完整环境验收。

## 1. 目的

本模块为自动施压控制器提供确定性的数字被控对象，覆盖执行器速度响应、位置限位、探头接触、组织顺应性、迟滞/松弛和传感观测。所有数值均为`*_au`相对单位，不代表真实人体或机械参数。

## 2. 模型结构

- 输入：归一化电机命令`[-1, 1]`；
- 状态：位置、速度、接触载荷、迟滞内部状态；
- 真值输出：真实位置、速度和载荷；
- 观测输出：带噪声、偏置、量化、延迟、冻结、断线和饱和的传感值；
- 时间：固定整数tick，不使用墙钟时间。

执行器使用一阶速度响应，并限制速度和加速度。接触前载荷为0；接触后使用线性项、二次项、压入方向阻尼以及一阶松弛/迟滞项。

## 3. 实现边界

`D3Plant`只负责物理与观测演化：

- 会裁剪归一化命令和物理位置；
- 会产生上下限位状态；
- 不决定哪个控制状态允许运动；
- 不执行软/硬载荷安全上限；
- 不实现PID、ABORT、故障优先级或锁存。

这些裁决分别属于D3-C控制器和D3-D安全状态机，不能塞进被控对象以绕过分层测试。

## 4. 确定性

- 固定`integration_period_us`；
- 噪声使用显式seed；
- `reset()`恢复初始状态和随机序列；
- 相同配置、seed、命令与故障输入必须生成完全相同的观测；
- 不同seed只改变观测噪声，不改变真值轨迹。

## 5. 观测与故障

| 能力 | 行为 |
|---|---|
| bias | 在真值上增加显式偏置 |
| noise | 使用确定性伪随机高斯噪声 |
| quantization | 按配置步长量化 |
| delay | 载荷观测按固定tick延迟 |
| freeze | 保持首次冻结时的观测值，真值继续演化 |
| disconnect | 值设为`None`且有效位为false |
| saturation | 观测裁剪到显式范围 |

控制器后续必须依赖有效位，而不能把`None`、冻结值或饱和值当作正常载荷。

## 6. 测试范围

`tests/test_d3_plant.py`覆盖：

- 接触前自由运动和零载荷；
- 接触后的正载荷；
- 卸载回到下限位与零载荷；
- 位置、速度和命令限幅；
- 不同顺应性参数；
- 同seed复现和不同seed差异；
- 断线、冻结、偏置、量化、延迟和饱和；
- reset完整重放；
- 非法配置和非有限命令阻断。

## 7. 未证明内容

- 电机、丝杆、探头、摩擦和间隙；
- 真实传感器噪声、延迟、量化和失效分布；
- 真实安全限位和释放时间；
- 人体安全性或舒适性。

这些项目必须保留到H1以后通过台架和实物辨识。

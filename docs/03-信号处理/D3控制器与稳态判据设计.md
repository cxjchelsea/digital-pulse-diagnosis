# D3 控制器与稳态判据设计

## 1. 范围

D3-C 在 D3-B 虚拟执行机构与受力对象模型之上增加确定性闭环控制。全部量均为仿真相对单位，本实现不构成人体安全限值或医疗诊断能力。

本工作包包含目标斜坡、固定周期离散 PID、归一化输出限幅、条件积分与反算抗饱和、连续稳态窗口判定。状态机、故障优先级、安全监控与急停属于 D3-D/D3-E。

## 2. 控制链

`请求目标力 → 目标斜坡 → PID → 输出限幅 → D3-B 被控对象 → 力/力变化率反馈`

控制周期由 `TimingConfig.control_period_us` 唯一决定。相同初始条件和输入序列必须产生逐字段相同结果。

## 3. 算法约束

- 目标每周期最大变化量为 `target_slew_au_s × dt`，上升与下降均受约束。
- PID 使用误差差分项；目标斜坡降低设定值突变引起的微分冲击。
- 输出限制在 `[-output_limit, output_limit]`。
- 若误差会把已饱和输出继续推向饱和方向，则暂停常规积分；随后使用反算项把积分状态拉回可控范围。
- 积分贡献始终限制在 `[-integral_limit, integral_limit]`。
- 无效测量不进入 PID，输出为零且清空稳态计时；是否锁存故障由后续安全层决定。
- 控制器禁用时输出为零并重置动态状态，避免跨阶段继承积分。

## 4. 稳态判据

单周期同时满足以下条件才累计稳态时间：

1. `|目标误差| <= tolerance_force_au`；
2. `|力变化率| <= tolerance_rate_au_s`；
3. 测量有效。

任一条件中断立即清零。连续样本数达到 `ceil(min_stable_s / dt)` 后才报告 `stable=true`，不使用单点命中判稳。

## 5. 验收

```bash
python -m pytest tests/test_d3_controller.py -q
python -m pytest -q
```

专项测试覆盖斜坡、正负限幅、持续饱和、误差反转恢复、禁用复位、无效测量、稳态连续性、变化率门限、确定性和非法输入。

通过标准：专项测试全绿、全量回归无退化；实际测试数量以运行输出为准并记录到 PR，不预先宣称通过。

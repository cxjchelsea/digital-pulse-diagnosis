# 信号处理方案

## 1. 本层职责

信号处理层位于采集硬件和分析软件之间，回答三个问题：

1. 数据是否完整；
2. 当前波形是否可信；
3. 如何把原始ADC序列转换成可比较的标准脉搏数据。

本层不负责疾病诊断，也不把一条形状漂亮的波形自动视为有效数据。

## 2. 输入与输出

### 输入

- 原始ADC计数；
- 静态接触力；
- 参考PPG/ECG通道；
- 电机位置和目标力；
- 设备状态与事件；
- 采样时间戳和序号；
- 传感器、探头、硬件和校准版本。

### 输出

- 数据完整性报告；
- 工程单位波形；
- 稳定采集窗口；
- 信号质量类别和置信度；
- 滤波后的标准波形；
- 单次心搏片段；
- 客观时域、频域和压力响应特征；
- 无效原因与重采建议。

## 3. 处理流水线

```mermaid
flowchart LR
    A["L0 原始帧"] --> B["完整性检查"]
    B --> C["校准与单位换算"]
    C --> D["稳态窗口识别"]
    D --> E["质量与伪影检测"]
    E --> F["基线与滤波"]
    F --> G["逐搏检测与切分"]
    G --> H["特征与压力响应"]
```

### 3.1 完整性检查

检查：

- CRC；
- 帧序号连续性；
- 时间戳单调性与抖动；
- ADC削顶；
- 传感器断线；
- 缓冲区溢出；
- 会话是否正常结束。

失败数据保留，但标记为不可用于模型。

### 3.2 校准与工程单位

- ADC计数转换为电压；
- 载荷通道换算为力；
- 若探头有效接触面积已知，才派生局部压力估计；
- 保存校准曲线、残差、日期和适用温度；
- 不覆盖原始计数。

### 3.3 稳定窗口

排除：

- 探头接触瞬间；
- 电机运动和压力换挡；
- 尚未达到载荷稳态的区间；
- 急停和退回；
- 明显运动伪影。

稳态判据可结合载荷误差、载荷变化率、电机状态和最短持续时间。

### 3.4 信号质量

首版使用规则与可解释特征，后续再训练质量模型。

质量类别：

- `good`；
- `no_contact`；
- `weak_signal`；
- `motion_artifact`；
- `sensor_saturation`；
- `pressure_transition`；
- `unstable_baseline`；
- `irregular_or_unknown`。

分析软件只有在质量达到门槛时才计算正式结果。

### 3.5 基线和滤波

可能需要：

- 去趋势或高通处理基线漂移；
- 低通抑制高频电子噪声；
- 工频陷波仅在确认存在工频污染后使用；
- 运动伪影区间使用掩码，不强行“修复”为正常波形。

必须区分：

- 离线零相位滤波：用于研究和复核；
- 实时因果滤波：用于在线显示和判断。

不能用离线滤波结果宣称实时算法性能。

### 3.6 逐搏切分

- 检测脉搏足点、主峰和可能的重搏切迹；
- 结合参考通道核对漏检和重复检出；
- 保存原始时间坐标；
- 对异常搏动单独标记；
- 既保存未归一化片段，也生成形态比较用归一化副本。

### 3.7 特征

基础特征：

- 心率与心搏间期；
- 主峰幅值；
- 上升/下降时间；
- 半峰宽；
- 曲线面积和斜率；
- 周期间变异；
- 频域能量分布；
- 各压力平台的幅值、形态和质量；
- 最佳有效压力区间。

浮、沉等脉象不属于主体信号处理输出。只有H6外部条件具备时，才可基于固定多压力协议和专业标签开展独立研究；开源资料不能替代本设备专业真值。

## 4. 数据分层

| 层级 | 内容 | 是否可覆盖 |
|---|---|---|
| L0 | 原始二进制帧和设备事件 | 否 |
| L1 | 校准后的工程单位数据 | 否，生成新版本 |
| L2 | 质量掩码、滤波波形、逐搏片段 | 否，生成新版本 |
| L3 | 特征和模型输入 | 否，记录参数 |
| L4 | 模型输出和人工标注 | 否，记录模型版本 |

每个派生结果记录输入数据ID、代码提交、参数和生成时间。

## 5. 仿真验证

模拟器至少生成：

- 正常周期波；
- 不同心率；
- 基线漂移；
- 随机噪声；
- 工频；
- 压力切换；
- 运动冲击；
- 削顶；
- 丢帧；
- 节律变化。

用固定随机种子建立黄金数据，保证算法更新后可以回归测试。

## 6. 验收指标

- 丢帧和CRC错误检出率；
- 黄金数据心搏检出率；
- 心率MAE；
- 有效窗口覆盖率；
- 伪影误报与漏报；
- 实时处理延迟；
- 相同输入重放的一致性；
- 不同滤波版本对关键形态的影响。

所有指标在开发集上冻结阈值，再运行测试集。

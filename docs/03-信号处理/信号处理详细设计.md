# 信号处理详细设计

## 1. P0实现

当前实现提供：

- 帧CRC、长度、版本和枚举检查；
- 确定性合成波形；
- 移动平均基线估计和去基线；
- 局部极值＋动态阈值的基础峰检测；
- 基于中位心搏间期的心率估计；
- 常量、非有限值、时长、削顶和心搏覆盖的质量检查。

这是一条透明基线，不是最终医学信号算法。

## 2. 处理约束

- 原始数据保留；
- 离线和实时算法分开评价；
- 归一化副本不得替代真实幅值；
- 压力切换窗口不得参与形态分析；
- 不确定或异常节律不得强行修复为正常；
- P1接入真实硬件后重新确定频带和阈值。

## 3. 后续算法候选

- 鲁棒去趋势；
- 明确抗混叠后的低通/带通；
- 参考通道辅助对齐；
- SQI信号质量指标组合；
- 模板相关和逐搏异常检测；
- 压力平台稳定窗口识别；
- 多压力幅值、宽度和形态响应。

## 4. 验收

- 75 bpm黄金信号误差小于1 bpm；
- 常量信号标签为`no_signal`；
- 相同输入得到相同峰位置；
- CRC错误在进入信号算法前被拒绝；
- 质量标签带有具体原因。

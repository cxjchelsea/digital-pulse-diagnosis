# D1–D3数字原型扩展实施总方案

版本：0.1.0；状态：当前执行入口。

## 1. 目标与边界

在购买硬件前，把仍可由软件、模型和故障注入可靠验证的能力做到最大闭环，为H1硬件接入冻结接口和验收方法。

数字阶段证明软件逻辑、通信协议和控制策略在已定义模型中成立；不证明真实传感器、真实机械结构、人体安全或医学有效性。

## 2. 阶段总览

| 阶段 | 核心问题 | 主要交付 | 退出标准 |
|---|---|---|---|
| D0 | 基础数据闭环是否成立 | P0模拟器、协议、存储、处理、API、Web | 已通过并合并 |
| D1 | 真实设备接入的软件准备是否完整 | 设备抽象、虚拟串口、握手、能力、重连、固件行为模拟 | 模拟设备和串口端到端通过 |
| D2 | 标定与多压力实验流程是否完整 | 标定模拟、压力profile、质量/压力响应、实验报告 | 正常与异常标定场景通过 |
| D3 | 自动施压与安全逻辑是否可验证 | 被控对象模型、控制器、状态机、故障注入、安全回归 | 全部安全故障到达预期安全态 |
| H1 | 真实传感链是否成立 | MCU、ADC、传感器、手动单点波形 | 必须用实物完成 |

D4–D6不设置为独立前置阶段。多人分布、空间寻脉和脉象标签可以搭建软件骨架，但算法结论必须等待H4–H6真实数据。

## 3. D1：设备通信数字原型

### 实现

- DeviceTransport统一接口，支持模拟流、虚拟串口和未来真实串口；
- 固件行为模拟器，按250 Hz输出协议v0；
- HELLO、CAPABILITIES、START、STOP、ABORT、ACK/NACK；
- 设备ID、固件版本、通道、采样率、缩放和校准版本；
- 串口分片、粘包、延迟、断连、重连和端口消失模拟；
- 原始字节先落盘，再解析；
- 不完整会话、恢复事件和质量摘要；
- Web设备连接状态、错误原因和重试入口。

### 测试

- 黄金帧跨实现一致；
- 随机分片/粘包不改变解析结果；
- CRC、序号、时间戳、未知版本被识别；
- UI阻塞不影响原始落盘；
- 断连后会话被标为不完整；
- ABORT优先于普通命令。

## 4. D2：标定与多压力数字实验

### 实现

- ADC计数到工程值的版本化标定模型；
- 零点、两点、多点标定流程；
- 标定过期、系数缺失、非线性和漂移故障；
- 可配置压力profile、稳定时间和采集时间；
- 多压力波形、迟滞、噪声、削顶和运动伪影生成；
- 压力—幅值、质量和心率响应；
- 台架实验元数据、原始数据导出和自动报告；
- 决策矩阵和候选评分工具。

### 测试

- 已知系数可恢复工程值；
- 错误/缺失标定阻断工程值输出；
- 压力步骤、稳定窗口和报告可重现；
- 质量失败不进入正式分析；
- 同种子结果一致，不同种子保留统计分布。

## 5. D3：自动施压与安全控制仿真

### 实现

- 简化执行器—软组织被控对象模型；
- 位置、速度、载荷、顺应性、摩擦和延迟参数；
- 接近、接触、稳定、采集、换挡、退回、故障状态机；
- PID/限速控制器和抗积分饱和；
- 目标profile、稳态判据、超时与卸载；
- 上下限位、急停、超载、传感器断线、电机卡滞、上位机失联和看门狗故障注入；
- 阶跃响应、超调、稳态误差和释放时间报告；
- Web控制仿真面板与状态时间线。

### 安全原则

仿真中的载荷数值是模型参数，不是人体安全值。ABORT/RETRACT必须由设备侧状态机执行，不依赖Web界面或分析模型。

### 测试

- 每种故障到达预期安全态；
- 超限时禁止继续加压；
- 通信失联触发本地退回；
- 控制器饱和不会无限积分；
- 相同模型与配置结果可重现；
- 长时间运行无序号、缓冲或状态异常。

## 6. 实施顺序

1. D1协议命令与设备能力规范；
2. 设备传输抽象和虚拟串口；
3. D1端到端、断连和故障测试；
4. D2标定模型、压力生成器和实验报告；
5. D2异常标定与质量门控；
6. D3被控对象、控制器和安全状态机；
7. D3故障矩阵与自动回归；
8. 形成数字原型验收报告；
9. 冻结H1最小采购BOM；
10. 进入真实硬件采购与调试。

## 7. 进入H1的条件

- D1–D3自动测试全部通过；
- 模拟与虚拟串口共用正式协议；
- 原始数据、配置、标定和报告可追溯；
- 安全状态机的故障矩阵通过；
- 硬件仍待实测的参数全部标为未知；
- BOM中每项采购对应一个无法再靠仿真回答的问题；
- 没有把模拟性能写成真实设备指标。

## 8. 购买前不会完成的内容

- 真实ADC有效位数和噪声；
- 传感器灵敏度、漂移和迟滞；
- 模拟前端最终增益与带宽；
- 探头结构和人体载荷；
- 电机振动、机械间隙和真实释放时间；
- 真人重戴有效率、自动寻脉成功率；
- 脉象或疾病模型有效性。

# 项目定位与成果声明规范

## 1. 正式定位

项目正式名称：

> 自适应桡动脉脉搏数字化采集与客观分析系统

英文展示名：

> Adaptive Radial Pulse Acquisition and Objective Analysis System

项目目标是构建包含采集硬件、嵌入式通信、信号处理、控制仿真、实时软件和工程验证的完整系统。项目不以中医脉象识别或疾病诊断作为完成条件。

## 2. 核心能力

- 桡动脉机械搏动和接触力的数字化采集；
- 原始数据、设备状态、标定和版本的完整追溯；
- 信号质量、心率、节律、形态和压力响应；
- 自动施压控制与故障安全；
- 重戴、跨日、不同操作者的重复性验证；
- 自动寻找高质量采集位置；
- 实时设备软件、实验管理和报告。

## 3. 不属于主体范围

在缺少中医师、伦理和专业标注时，以下能力不属于主体交付：

- 浮、沉、滑、涩、弦等脉象识别；
- 中医证候判断；
- 疾病诊断或治疗建议；
- 临床有效性或医疗器械性能声明。

开源文献和公开数据可用于算法预研与数据框架验证，但不能替代本设备实测、专业标注或临床验证。

## 4. H6外部研究扩展

H6调整为可选外部依赖，不影响项目主体完成。

只有同时满足以下条件才启动：

- 固定硬件、采集协议和数据版本；
- 获得合格中医师合作；
- 建立标签手册、盲法和分歧处理；
- 完成伦理、隐私和授权；
- 按受试者隔离训练与测试；
- 有足够样本和独立验证设计。

不满足条件时，最多实现标签Schema、标注工具、多标注者一致性和公开数据基线，不输出脉象识别结论。

## 5. 项目完成标准

| 目标 | 对应阶段 |
|---|---|
| 软件与数字孪生原型 | D0–D3 |
| 真实传感与嵌入式采集 | H1–H2 |
| 自动施压软硬件闭环 | H3 |
| 多人重复性和完整工程验证 | H4 |
| 自动寻脉扩展 | H5 |
| 中医脉象研究 | H6，可选且依赖外部资源 |

项目主体在H4完成；H5是工程增强；H6不是简历项目成立的前置条件。

## 6. 简历声明边界

- D0–D3：可声明设备软件、信号处理、数字孪生、控制和故障注入；
- H1–H2：可声明嵌入式采集、传感器、ADC、标定和真实波形；
- H3：可声明自动施压闭环与安全状态机；
- H4：可声明多人重复性，但只能使用真实实验数字；
- 仅使用模块时，不声明独立PCB或高级模拟硬件设计能力；
- 不使用“AI脉诊设备”“诊断准确率”“临床有效”等名称或指标。

## 7. 对外统一用语

推荐：

- 客观脉搏参数；
- 压力响应；
- 信号质量；
- 自动寻脉；
- 工程验证；
- 研究原型、非医疗用途。

避免：

- 智能诊断；
- 中医脉象已经识别；
- 临床级；
- 医疗级精度；
- 能判断疾病。

# 路线图

时间是建议范围，不是承诺日期。进入下一阶段必须先通过上一阶段门。

## Phase 0：基础学习与软件仿真（2–4周）

### 学习

- 电压、电流、电阻、分压、电桥；
- ADC采样率、量化、有效位数；
- 运放、滤波、噪声和接地；
- ESP32基本GPIO、定时器、SPI/I²C、串口；
- 基础机械限位和电机安全。

### 实现

- 项目需求与协议v0；
- Python脉搏信号模拟器；
- 设备状态模拟器；
- 实时采集服务；
- 最小Web波形界面；
- 黄金数据和自动测试。

### 阶段门

- 模拟器连续运行30分钟无数据损坏；
- 可检测丢帧、CRC错误和设备故障；
- 原始数据可重放得到一致结果。

## Phase 1：手动单点采集（4–8周）

### 实现

- MCU固定频率采样；
- 2–4类传感器对照；
- 原始数据USB传输；
- 手动探头与手腕托架；
- 参考PPG/心率同步；
- 基础滤波与逐搏检测。

### 阶段门

- 真实脉搏清晰可辨；
- 不发生持续削顶；
- 多次重放结果一致；
- 心率与参考设备满足冻结目标；
- 重戴后仍能获得有效波形。

## Phase 2：接触力同步与结构优化（4–6周）

### 实现

- 静态载荷传感器；
- 载荷标定；
- 三种探头对比；
- 手动多压力采集；
- 压力响应可视化；
- 信号质量规则v1。

### 阶段门

- 载荷测量重复性满足目标；
- 同一人的压力响应趋势可复现；
- 选定动态传感器、ADC和探头方案。

## Phase 3：自动施压闭环（6–10周）

### 实现

- 电机丝杆机构；
- 上下限位和急停；
- 压力闭环；
- 稳态检测；
- 自动压力profile；
- 故障和释放状态机；
- 仿体安全回归。

### 阶段门

- 仿体压力阶跃指标满足目标；
- 所有故障注入均能安全处理；
- 人体渐进测试无异常；
- 自动流程获得有效多压力数据。

## Phase 4：多人重复性验证（4–8周）

### 实现

- 10–20名健康成人工程验证；
- 跨日、重戴、不同操作者测试；
- 数据质量模型v1；
- 完整实验报告；
- 演示视频和项目页面。

### 阶段门

- 有效信号率、心率误差和重复性有诚实量化结果；
- 主要失败模式已排序；
- 是否进入自动寻脉有数据依据。

这一步完成后，项目已经足以作为软硬件系统核心简历项目。

## Phase 5：自动寻脉（8–12周）

### 实现

- 横向阵列或机械扫描方案A/B；
- 空间质量图；
- 自动选点；
- 失败检测；
- 不同腕围和重戴验证。

### 阶段门

- 自动寻脉达到冻结指标；
- 相比人工单点定位具有明确收益；
- 复杂度、成本和可靠性可接受。

## Phase 6：中医师合作与AI脉象研究（长期）

### 前置

- 固定设备版本；
- 固定采集协议；
- 伦理、隐私和数据治理；
- 至少两名中医师；
- 统一标签手册；
- 受试者级数据划分。

### 研究顺序

- 浮/沉；
- 迟/数；
- 强/弱、宽/细；
- 滑、涩、弦等复杂多标签；
- 多位置寸关尺；
- 结构化结果的Agent解释。

## 每阶段展示物

| 阶段 | 展示物 |
|---|---|
| P0 | 模拟器视频、协议、测试 |
| P1 | 实时真人波形、硬件照片、参考对照 |
| P2 | 压力—波形曲线、传感器对比报告 |
| P3 | 自动施压视频、阶跃响应、安全演示 |
| P4 | 多人重复性报告、完整系统演示 |
| P5 | 自动寻脉空间图和成功率 |
| P6 | 受试者隔离的模型报告和医生一致性 |

## 暂不排期

- 柔性三通道腕带；
- 电池与无线；
- 小型化PCB；
- 医疗器械注册；
- 患者临床试验；
- 疾病辅助诊断。

这些任务只有在技术与产品目标明确后重新立项。

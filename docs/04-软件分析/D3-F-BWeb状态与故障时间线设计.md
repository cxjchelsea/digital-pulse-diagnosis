# D3-F-B Web状态与故障时间线设计

## 范围

D3-F-B 在保留现有D0模拟会话和D2标定实验入口的基础上，增加D3故障矩阵运行、报告摘要、安全事件时间线和确定性重放展示。

## 页面信息

- D3服务阶段与虚拟设备连接状态；
- 14类故障矩阵运行入口；
- 通过数、失败数、分析门控和报告摘要；
- 每个安全事件的设备tick、主故障、动作、目标状态、检测延迟和最终命令；
- 报告确定性重放结果；
- 固定显示相对单位、非人体安全验证和非医疗用途边界。

页面不提供直接写电机命令、绕过阈值、清除急停或强制解除锁存故障的入口。

## 验收

```bash
cd web
npm install
npm run build
npm run dev
```

手动验收：

1. 后端与前端启动后显示D3服务正常；
2. 点击“运行D3矩阵”，显示14个事件且全部通过；
3. 每个事件显示fault、action、state、检测tick和命令；
4. 点击“确定性重放”，显示“逐字段与哈希一致”；
5. D2实验与原模拟会话入口仍可使用；
6. 窄屏下时间线不横向溢出；
7. 页面不出现真实N、mmHg或人体安全结论。

本阶段通过后，D3-F-A与D3-F-B共同满足D3-F交付；最终D3退出条件仍需D3-G集成验收。

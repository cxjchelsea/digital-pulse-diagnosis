# 采集硬件方案

## 1. 本层职责

采集硬件层负责把人体桡动脉的机械搏动转换为包含时间、位置、接触力和设备状态的原始数字数据，为信号处理层提供可校准、可重复、可追溯的输入。本层不判断脉象或疾病。

## 2. 总体策略

不从柔性材料或医疗级整机开始。先使用成熟模块验证传感原理、信噪比、探头结构和压力响应，再决定原理图和PCB。

采购顺序必须跟随阶段门，避免一次购买完整系统后无法定位问题。

## 3. 两条测量链路

### 3.1 动态脉搏链路

目标：测量心搏造成的微小动态变化。

候选原理：

| 原理 | 优点 | 风险 | 早期用途 |
|---|---|---|---|
| 压阻/力敏 | 易获得、结构直观 | 漂移、迟滞、批次差 | 快速筛选 |
| 电容压力 | 灵敏、功耗低 | 寄生电容、结构要求 | 候选 |
| 压电 | 动态响应好 | 不能可靠测静态力 | 动态辅助 |
| PPG | 模块成熟、心率参考好 | 不是触诊压力本身 | 同步参考 |
| MEMS气压＋气囊 | 接触均匀 | 气路和动态耦合复杂 | 后续腕带 |

首批应采购2–4种不同原理或量程的候选，而不是大量购买同一型号。

### 3.2 静态载荷链路

目标：测量探头施加的总体接触力。

建议使用小量程称重传感器或等效载荷传感器配合桥式ADC。它主要服务于压力控制和标定，不承担全部脉搏形态测量。

注意“力”和“压力”不同：

[
P = \frac{F}{A}
]

探头接触面积变化会改变局部压力。早期应同时记录力、探头几何尺寸和接触结构，不轻易把载荷直接称为kPa。

## 4. 首版模块

| 模块 | 建议 | 选择依据 |
|---|---|---|
| MCU | ESP32-S3开发板 | 入门资料、USB、性能和成本 |
| ADC | 外置16–24位候选模块 | 关注有效位数、噪声和同步性 |
| 动态传感器 | 多原理小批对比 | 通过实测选型 |
| 载荷传感器 | 小量程称重/力传感器 | 静态稳定和易标定 |
| 参考通道 | 商用PPG模块或参考设备 | 对齐心搏和心率 |
| 电机 | 小型步进电机 | 低速可控 |
| 传动 | 丝杆滑台 | 位置直观、易限位 |
| 驱动 | 可限流、微步驱动器 | 降低振动和发热 |
| 限位 | 上下双限位 | 硬件安全边界 |
| 急停 | 常闭物理按钮优先 | 断线可检测 |
| 电源 | 隔离/低压开发电源 | 人体连接时优先安全 |
| 结构 | 3D打印托架＋标准型材 | 快速更换探头 |

在连接人体的早期原型中优先使用低压供电和笔记本电池供电场景，谨慎处理市电、USB地和外部仪器地之间关系。

## 5. 传感器筛选实验

每个候选传感器执行相同测试：

1. 零载噪声；
2. 固定载荷下10分钟漂移；
3. 多级加载/卸载迟滞；
4. 重复加载一致性；
5. 不同温度/预热时间；
6. 人工模拟脉动响应；
7. 实际腕部静止采集；
8. 轻微移动和重新佩戴；
9. 输出饱和和恢复；
10. 与参考心率的一致性。

记录：

- 型号、批次、序列号；
- 激励方式；
- 增益和滤波；
- 采样率；
- 探头结构；
- 原始数据文件；
- 测试脚本版本。

## 6. 探头实验

至少制作三种可替换探头：

- 小圆头：空间定位敏感；
- 中等圆头：平衡局部性和稳定性；
- 柔性接触头：减少滑动和压力集中。

比较：

- 有效信号幅度；
- 信噪比；
- 位置敏感性；
- 运动伪影；
- 重复佩戴一致性；
- 舒适度；
- 清洁和更换便利性。

不在没有实测前确定“最佳指尖形状”。

## 7. 模拟前端

设计检查项：

- 传感器激励稳定；
- 输入共模范围；
- 仪表放大器/运放单电源适配；
- 增益不会在最大静载荷下饱和；
- 高通不会破坏所需低频形态；
- 低通具备抗混叠作用；
- ADC参考与模拟地布局合理；
- 数字电机噪声与模拟采集隔离；
- 输入保护和断线诊断。

首版模块验证后，才进入KiCad原理图和PCB。

## 8. 自动施压结构

### 8.1 控制流程

- 快速空行程接近；
- 接近皮肤前降速；
- 通过载荷阈值判断接触；
- 缓慢到达目标力；
- 等待压力变化率和振动满足稳定条件；
- 电机停机或进入低扰动保持；
- 采集固定时长；
- 切换下一平台；
- 完成后完全退回。

### 8.2 安全机制

至少包含：

- 机械最大行程；
- 上下限位开关；
- MCU本地载荷上限；
- 目标压力超时；
- 电机卡滞检测；
- 急停按钮；
- 上位机失联退回；
- 看门狗；
- 断电后手动释放；
- 探头圆滑、无锐边。

压力上限必须经过仿体与低风险渐进实验确定，不在文档阶段拍脑袋设置人体安全值。

## 9. 仿体与台架

在人体测试前准备：

- 标准砝码或已知载荷用于标定；
- 弹性硅胶/泡棉用于模拟软组织；
- 可重复脉动源，可由小泵、扬声器驱动膜片或机械偏心机构实现；
- 示波器；
- 万用表；
- 后期使用逻辑分析仪；
- 如果条件允许，使用已校准力计做交叉验证。

## 10. PCB进入条件

同时满足以下条件才画首版PCB：

- 传感器原理确定；
- 增益和带宽实测确定；
- ADC接口与采样率确定；
- 电机噪声路径明确；
- 原型连续采集稳定；
- 至少完成一轮多人重复实验；
- 模块连接已成为主要可靠性瓶颈。

PCB不是项目开始标志，而是已经掌握关键参数后的工程固化。

## 11. BOM预算分段

不给出未经询价的固定金额，采购时建立含日期和来源的BOM。

- B0学习与仿真：开发板、基础工具；
- B1单点采集：候选传感器、ADC、面包板、参考PPG；
- B2载荷与结构：称重传感器、3D打印探头、手腕托架；
- B3自动施压：电机、丝杆、驱动、限位、急停；
- B4阵列：多通道ADC、阵列或扫描机构；
- B5工程化：PCB、外壳、EMC/安全预验证。

每阶段只在上一阶段通过后采购下一批。

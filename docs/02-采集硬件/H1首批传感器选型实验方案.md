# H1首批传感器选型实验方案

## 1. 目标

本方案属于H1实体验证。D1–D3全部通过并冻结最小BOM后，通过小批量采购和统一台架实验确定手动单点采集原型的候选组合，而不是根据宣传参数直接决定最终型号。

本实验需要回答：

1. 哪类传感器能稳定捕获桡动脉动态信号；
2. 动态脉搏和静态接触力是否需要分通道测量；
3. 哪种ADC、增益和探头组合具有更好的信噪比与重复性；
4. 哪些候选应进入人体工程验证，哪些应淘汰。

## 2. 本轮范围

### 需要比较

- 2～4种动态脉搏传感候选；
- 1～2种静态载荷传感候选；
- 1～2种外置ADC/采集模块；
- 3种可更换探头结构；
- 一个参考PPG或心率通道。

### 暂不采购

- 压力阵列；
- 气泵和气囊；
- 自动施压电机；
- 电池和无线模块；
- 定制PCB；
- 寸关尺三通道结构。

这些设备只有在单点采集方案通过阶段门后再采购。

## 3. 候选类别

| 角色 | 候选类别 | 主要用途 | 主要风险 |
|---|---|---|---|
| 动态脉搏 | 压阻/力敏 | 快速验证接触式压力波形 | 迟滞、漂移、批次差 |
| 动态脉搏 | 压电 | 捕获微小动态搏动 | 不能可靠测静态载荷 |
| 动态脉搏 | 电容压力 | 高灵敏动态测量 | 寄生电容和结构敏感 |
| 参考通道 | PPG | 对齐心搏和检查心率 | 不是触诊压力 |
| 静态载荷 | 小量程称重传感器 | 记录总体接触力 | 机械安装与温漂 |
| ADC | 16～24位外置ADC | 读取弱模拟信号 | 标称位数不等于有效位数 |

具体型号、价格和购买来源应通过单独的带日期BOM冻结。没有数据手册或来源不可靠的模块不进入最终候选。

## 4. 采购记录字段

每个器件记录：

- candidate_id；
- 厂商与完整型号；
- 购买链接和购买日期；
- 单价、数量和交期；
- 量程、灵敏度、噪声、频响；
- 激励方式和供电；
- 输出接口；
- 封装与安装方式；
- 数据手册版本；
- 批次/序列号；
- 替代型号；
- 预期验证的假设。

## 5. 台架准备

- ESP32-S3开发板；
- 候选ADC和模拟前端模块；
- 万用表；
- 示波器；
- 标准砝码或已知载荷；
- 弹性硅胶/泡棉仿体；
- 可重复脉动源；
- 3D打印或可替换探头；
- 参考PPG；
- D1冻结的正式设备协议、传输抽象和采集软件（兼容D0/P0 v0数据帧）。

在连接人体前先完成所有台架和仿体实验。

## 6. 统一测试流程

### T-HW-001 零载噪声

- 传感器安装但不加载；
- 预热后连续采集10分钟；
- 记录均值、标准差、峰峰值和频谱；
- 比较不同供电、USB连接和电机模拟干扰条件。

### T-HW-002 静态漂移

- 施加固定载荷；
- 连续记录10分钟；
- 计算零点漂移、斜率和温度变化；
- 检查预热时间是否影响结论。

### T-HW-003 加载与卸载迟滞

- 按相同阶梯逐级加载和卸载；
- 每级等待稳态；
- 绘制加载/卸载曲线；
- 计算迟滞误差和非线性。

### T-HW-004 重复加载

- 对同一载荷重复至少10次；
- 完全卸载后重新加载；
- 计算均值、标准差和变异系数。

### T-HW-005 动态脉动响应

- 使用可重复脉动源；
- 在不同静态载荷上叠加相同动态输入；
- 比较幅值、信噪比、频率响应和波形失真；
- 确认大静载荷是否使动态通道饱和。

### T-HW-006 探头对比

比较小圆头、中圆头和柔性接触头：

- 信号幅值；
- 信噪比；
- 位置敏感性；
- 滑动伪影；
- 重装一致性。

### T-HW-007 初步腕部采集

只有前述测试通过后执行：

- 手动定位关部；
- 同步记录动态通道、静态载荷和参考PPG；
- 每种方案连续采集30～60秒；
- 完全拆下后重装至少3次；
- 保存失败样本，禁止只选最佳曲线。

这一步只是健康成人工程验证，不用于脉象或疾病判断。

## 7. 评价指标

| 指标 | 定义 |
|---|---|
| 零载RMS噪声 | 稳态零输入的均方根波动 |
| 漂移率 | 固定载荷下单位时间基线变化 |
| 迟滞误差 | 同载荷加载与卸载输出差 |
| 重复性CV | 重复加载结果标准差/均值 |
| 动态SNR | 脉动有效成分相对噪声 |
| 削顶比例 | 达到ADC上下界的样本比例 |
| 心搏匹配率 | 与参考PPG逐搏匹配的比例 |
| 重装有效率 | 完全重装后仍得到有效信号的比例 |
| 成本与复杂度 | 器件、装配、校准和软件复杂度 |

## 8. 决策矩阵

各项评分采用1～5分，权重在看结果前冻结。

| 维度 | 建议权重 |
|---|---:|
| 动态信噪比 | 25% |
| 漂移与迟滞 | 15% |
| 重复性 | 20% |
| 重装有效率 | 15% |
| ADC/电路适配 | 10% |
| 结构与安装 | 5% |
| 成本与供应 | 5% |
| 后续阵列扩展 | 5% |

安全、饱和或断线诊断存在不可接受问题的候选直接淘汰，不使用加权分数掩盖硬性失败。

## 9. 阶段输出

完成后必须提交：

- 带日期和来源的首批BOM；
- 接线图和探头结构版本；
- 所有原始台架数据；
- 自动分析脚本；
- 传感器对比报告；
- 失败模式清单；
- 推荐组合与备选组合；
- 更新后的工程决策记录；
- 是否进入H1人体手动单点采集的结论。

## 10. H1采购与人体测试阶段门

### 10.1 H1采购启动条件

- D1设备通信、D2标定实验和D3安全控制仿真全部通过；
- 正式协议、数据Schema、标定记录和实验报告格式冻结；
- 每个采购项都对应一个无法继续通过仿真回答的问题；
- 采购型号、数量、原理图、来源和备选方案记录完整。

### 10.2 H1人体测试进入条件

完成采购、到货验收和台架实验后，只有同时满足以下条件才进入腕部采集：

- 至少一个动态通道能够在仿体上稳定捕获重复脉动；
- 静态载荷通道完成基本标定；
- ADC不持续削顶且有效分辨率满足需求；
- 探头结构不存在尖锐、夹压或无法快速移除的问题；
- 数据可以通过D1冻结的正式协议完整传输和保存；
- 失败数据能被识别并保留；
- 人体测试载荷范围将通过渐进实验确定，而不是沿用模拟器中的40/80/120。

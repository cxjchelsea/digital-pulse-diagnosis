# 验证与实验方案

## 1. 验证原则

- 先台架，后人体；
- 先证明数字链路，再验证真实测量；项目主体不以脉象解释为验收目标；
- 先冻结指标和分析方法，再运行测试集；
- 同时报告成功与失败；
- 不以窗口数代替受试者数；
- 目标值与实测值严格区分；
- 所有实验关联硬件、固件、校准和代码版本。

## 2. 验证层级

### V0 数字原型（D0–D3）

#### D0基础闭环

- 模拟器可重复；协议编解码；CRC与丢帧检测；
- 大文件连续落盘且UI不阻塞采集；
- 黄金数据算法输出稳定；数据Schema向后兼容。

#### D1设备通信

- 模拟流、虚拟串口和未来真实串口共用传输接口；
- 握手、能力、START/STOP/ABORT和ACK/NACK正确；
- 分片、粘包、延迟、端口消失、断连和重连可检测；
- 断连会话标记不完整，原始字节先于解析结果落盘。

#### D2标定与多压力

- 已知系数恢复工程值；错误、缺失和过期标定阻断输出；
- 压力步骤、稳定窗口、质量门控和报告可重现；
- 正常、漂移、迟滞、削顶、非线性和运动伪影场景覆盖。

#### D3控制与安全仿真

- 控制器阶跃、超调、稳态误差、饱和和释放时间可量化；
- 急停、超载、断线、卡滞、限位、失联和看门狗故障进入预期安全态；
- 仿真载荷只作为模型参数，不转换为人体安全值。

### V1 电路与传感器台架

验证：

- 零点噪声；
- 输入短接噪声；
- 静态漂移；
- 加载/卸载迟滞；
- 重复加载；
- 输出饱和；
- 采样率和有效带宽；
- 电机运行/停止时噪声差异；
- 电源与USB连接方式影响。

### V2 仿体

验证：

- 接触检测；
- 压力闭环阶跃响应；
- 超调、稳态误差和稳定时间；
- 不同等效硬度；
- 可重复脉动源；
- 机械限位；
- 急停、失联和看门狗退回；
- 探头结构对信号的影响。

### V3 健康成人工程验证

前提：

- 完成风险检查；
- 采用保守、渐进的载荷范围；
- 明确研究原型性质；
- 受试者知情并可随时终止；
- 不采集非必要身份信息；
- 不输出疾病判断。

### V4 可选外部研究（H6）

H6不属于项目主体完成条件。只有在硬件和协议固定，并同时具备医生合作、伦理、标签手册、盲法和独立验证时启动。开源资料只能用于方法预研，不能替代本设备专业标注或支持脉象、疾病结论。

## 3. 第一轮人体实验设计

### 3.1 目标

验证能否稳定获取波形，而不是训练AI。

### 3.2 样本

- 先由开发者自测；
- 安全与流程稳定后扩展至3–5名熟悉参与者；
- 再扩展至10–20名健康成人工程验证；
- 每人至少两个不同日期；
- 每次拆下设备后重新定位；
- 左右手是否都采集由协议版本明确。

人数是工程验证建议，不构成临床样本量结论。

### 3.3 条件控制

记录：

- 静坐休息时间；
- 姿势、前臂和手腕角度；
- 测量时间；
- 近期运动；
- 咖啡因；
- 进食；
- 室温；
- 腕围；
- 操作者；
- 设备和探头版本。

### 3.4 重复结构

每个位置建议：

1. 定位后连续采集3次；
2. 完全拆下并重新佩戴；
3. 再采集3次；
4. 不同日期重复；
5. 同步参考心率。

压力平台数量和目标载荷由H2真实实验冻结，不在人体实验前硬编码为“浮中沉”三个固定值；D2/D3中的载荷只是仿真参数。

## 4. 指标定义

### 4.1 数据完整性

- 期望采样数；
- 实际采样数；
- 丢帧率；
- 时间戳抖动；
- 不完整会话率。

### 4.2 信号质量

必须先冻结“有效信号”判据，可以综合：

- 心搏峰检出率；
- 周期一致性；
- 信噪比；
- 削顶比例；
- 运动伪影占比；
- 与参考心搏的匹配；
- 稳态窗口长度。

### 4.3 心率

与参考设备逐窗口比较：

- MAE；
- 偏差和一致性限界；
- 有效窗口覆盖率；
- 不能只报告相关系数。

### 4.4 压力控制

- 上升时间；
- 超调；
- 稳态时间；
- 稳态误差；
- 压力波动标准差；
- 故障释放时间。

### 4.5 重复性

对幅值、时间、形态和压力响应分别计算：

- 变异系数；
- ICC；
- Bland–Altman；
- 同次重测与跨日重测分开；
- 人内与人间变异分开。

归一化后的特征不能替代真实幅值重复性。

### 4.6 自动寻脉

- 成功定位并获得有效信号的会话比例；
- 与人工最佳点的空间偏差；
- 搜索时间；
- 失败检测率；
- 重戴后成功率；
- 不同腕围亚组表现。

## 5. 参考设备

阶段性选择：

- 普通手环/血氧仪：只用于早期心率合理性检查；
- 可靠PPG开发通道：用于同步与算法开发；
- ECG：逐搏时序参考；
- 已校准力计：载荷通道参考；
- 示波器/逻辑分析仪：采样与协议时序。

消费级手环不能作为所有波形形态和医学结论的金标准。

## 6. 安全测试

在人体前逐项验证：

- 急停按下后电机行为；
- 上位机强制关闭；
- USB拔出；
- MCU看门狗复位；
- 载荷传感器断线；
- 动态传感器饱和；
- 上下限位冲突；
- 电机卡滞；
- 目标值异常；
- 参数CRC或范围检查；
- 断电手动释放；
- 最大机械行程不造成危险挤压。

每次硬件修改后执行相关安全回归。

## 7. 实验记录模板

每次实验至少记录：

- experiment_id；
- 假设；
- 硬件/固件/软件版本；
- 校准记录；
- 受试者和会话数量；
- 纳入/排除标准；
- 预设指标；
- 原始数据位置；
- 分析脚本提交；
- 结果；
- 失败与异常；
- 结论；
- 下一决策。

## 8. 算法与可选H6验证要求

- 按受试者拆分；
- 训练、调优、内部测试、外部测试边界明确；
- 主体质量、异常和寻脉模型必须与规则基线比较，并按受试者拆分；
- H6启动时，医生标注者不可通过样本身份推断模型输出；
- H6启动时记录标注者经验、置信度和医生间一致性；
- 与简单规则和传统模型比较；
- 模型概率校准；
- 数据量—性能曲线；
- 影响因素与亚组分析；
- 对失败案例进行分类；
- 不因结果不理想而更换测试集。

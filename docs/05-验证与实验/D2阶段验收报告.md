# D2阶段验收报告

版本：1.0.0；状态：已验收，等待合并。

## 验收范围

D2验证的是无真实硬件条件下的“合成原始计数 → 版本化标定 → 多压力稳态实验 → 质量门控 → 压力响应 → 可追溯报告”完整数字链路，不代表真实传感器性能、人体安全压力或医学有效性。

## 已完成

- 标定记录、SHA-256校验、有效期和合成单位检查；
- offset、affine和piecewise_linear转换；
- 标定越界、篡改、过期和非单调阻断；
- 多压力Profile和数据驱动稳态判断；
- 显式种子、漂移、迟滞、噪声、削顶、运动、断线和永不稳定故障；
- 每步质量、心率、幅值、稳态统计和候选评分；
- 报告SHA-256、持久化、查询与确定性重放API；
- D2前端实验入口和相对单位声明；
- 标定与Profile机器可读Schema。

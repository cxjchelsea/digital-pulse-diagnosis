# D3阶段验收报告

版本：1.1.0
状态：通过（含收尾强化；以生成器与CI实测为准）
阶段：D3自动施压与安全控制数字仿真

## 1. 已完成范围

D3-A至D3-G已完成契约、被控对象、PID、安全状态机、故障矩阵、报告/API、Web时间线与集成。
D3收尾强化（Closeout Hardening）补齐：

1. **完整故障卸载闭环**（检测瞬间 + 卸载过程 + 终态）；
2. **ABORT API/Web → 设备侧状态机 → Plant卸载**真实闭环；
3. **1800秒完整链路**（Plant + PID + Safety + Device SM + 心跳）；
4. **可追踪验收证据生成器**与 D3-T01…T24 映射；
5. **GitHub Actions** Python/Web 自动化。

## 2. 正常Profile集成结果

默认Profile为20、40、60 `force_au`，最终状态为IDLE。

阈值：稳定时间不超过3秒、稳态误差不超过2 au、超调不超过10%。
状态时间线覆盖APPROACH、CONTACT、STABILIZE、ACQUIRE、STEP、RETRACT和IDLE；相同seed与配置报告哈希一致。

具体逐步数值以 `python scripts/generate_d3_acceptance.py` 生成的 `artifacts/d3-acceptance/acceptance.json` 中 `normal_profile.metrics` 为准，不在本文手填猜测值。

## 3. 安全证据分层

| 层次 | 含义 | 证据位置 |
|---|---|---|
| 检测瞬间安全响应 | 故障识别、优先级、检测延迟、瞬时命令与目标态 | `d3_fault_matrix` / 14类矩阵测试 |
| 完整卸载结果 | 停止加压、开始退回、接触解除、下限位、IDLE | `d3_closed_loop` 可退回用例 |
| 锁存故障结果 | 急停/卡滞/看门狗零输出并保持 `FAULT_LATCHED`，不虚构主动退回 | `d3_closed_loop` 锁存用例 |

ABORT 不依赖 Web/API 内部伪造；API 仅将 ABORT 送入设备侧状态机。

## 4. 30分钟模型时长结果

完整链路测试：`run_full_chain_long_hold(duration_s=1800)`。

覆盖模块：`plant`、`pid`、`safety`、`device_state_machine`、`heartbeat`。

验证：全部有限；命令在冻结范围；限位不被违反；心跳正常时不误触发 HOST_TIMEOUT / WATCHDOG_TIMEOUT；积分有界；事件与时间线结构有界；相同 seed 哈希稳定。

另保留原 Plant+PID `run_long_hold` 作为兼容回归，但不作为完整安全链路的唯一证据。

## 5. ABORT API/Web闭环

| 接口 | 作用 |
|---|---|
| `POST /api/experiments/d3/runs` | 创建可运行会话（可 `hold` 停留于 ACQUIRE） |
| `GET /api/experiments/d3/runs/{run_id}` | 查询状态/载荷/位移/命令/tick |
| `POST /api/experiments/d3/runs/{run_id}/abort` | 设备侧 ABORT（幂等） |
| `GET /api/experiments/d3/runs/{run_id}/events` | 会话事件与时间线 |

保留既有矩阵接口：`POST /run`、`GET /{sha256}`、`.../events`、`.../replay`。
Web 增加正常 Profile 控制区与 ABORT；前端不本地伪造设备安全事件。

## 8. 证据边界

本报告证明数字模型和软件安全逻辑在冻结配置下的行为。它不证明：

- 真实执行器推力、制动、卡滞和断电释放；
- 真实传感器量程、漂移、失效诊断或限位可靠性；
- 真实结构强度、接触面积、夹伤风险或人体安全载荷；
- 任何临床、诊断、脉象或治疗有效性。

所有真实硬件未知量仍进入 H1 待测参数清单。D3通过后只允许进入H1采购与台架验证，不允许直接进入人体自动施压实验。

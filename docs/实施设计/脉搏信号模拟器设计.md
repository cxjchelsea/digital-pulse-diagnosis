# 脉搏信号模拟器设计

## 1. 目标

在硬件到货前为协议、采集、信号处理和分析软件提供稳定、可复现的输入。模拟器是软件测试工具，不是人体血流动力学模型。

## 2. 信号组成

```text
输出 = 压力耦合增益 × 周期脉搏模板
     + 低频基线漂移
     + 工频干扰
     + 随机噪声
     + 可配置运动事件
```

周期模板包含主峰、反射波、切迹和重搏波的简化高斯组合。压力增益使用钟形研究曲线，只用于验证多压力软件流程。

## 3. 设备行为

- 压力平台包含稳定时间和采集时间；
- 载荷通过一阶响应接近目标；
- 稳定期输出STABILIZE；
- 有效采集期输出ACQUIRE；
- 所有样本使用正式二进制协议。

## 4. 可复现性

- 所有随机过程使用显式种子；
- 同配置和种子必须逐样本相同；
- 改变代码导致黄金数据变化时必须说明原因；
- 合成参数不能写作设备实测或人体指标。

## 5. 命令行

```bash
python -m digital_pulse.cli \
  --output simulated-session.bin \
  --sample-rate 250 \
  --heart-rate 72 \
  --forces 40 80 120 \
  --acquire-seconds 5
```

# 分析软件详细设计

## 1. 模块边界

```text
simulator -> protocol -> acquisition-service -> raw store
                                      |-> realtime stream -> web
raw store -> signal pipeline -> derived store -> analysis/report
```

## 2. P0代码布局

```text
src/digital_pulse/
├── protocol.py   # 二进制协议
├── waveform.py   # 合成脉搏
├── device.py     # 压力profile设备模拟器
├── signal.py     # 基础质控和心率
└── cli.py        # 生成模拟会话
```

## 3. 下一实现增量

### 采集服务

- 传输抽象：文件、模拟串口、真实串口；
- 帧解析和缓冲；
- 原始帧先落盘；
- 会话Manifest；
- WebSocket实时订阅；
- 断连与不完整会话。

### Web界面

- 设备状态；
- 新建匿名会话；
- 脉搏、载荷和目标值实时图；
- 状态机和故障；
- 信号质量与重采提示；
- 原始/处理波形对照。

### 分析

- 心率、心搏间期和基础形态；
- 各压力平台的质量与响应；
- 重复测量比较；
- 结果引用会话、处理参数和代码版本。

## 4. 门控规则

- CRC/长度/时间错误：拒绝对应数据；
- 会话不完整：报告标记不完整；
- 质量为invalid/no_signal：不输出正式参数；
- 未经实测验证的模块：界面标记“研究中”；
- P0不输出脉象和疾病结论。

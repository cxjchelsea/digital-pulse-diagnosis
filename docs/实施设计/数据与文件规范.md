# 数据与文件规范

## 1. 数据层级

| 层 | 内容 | 规则 |
|---|---|---|
| L0 | 原始二进制帧和事件 | 永不覆盖 |
| L1 | 校准后的工程单位数据 | 引用校准版本 |
| L2 | 质量、滤波和逐搏结果 | 引用算法与参数 |
| L3 | 特征和模型输入 | 可完全再生 |
| L4 | 模型输出和人工标注 | 引用模型/标注者版本 |

## 2. 会话目录

```text
session-id/
├── manifest.json
├── raw_frames.bin
├── events.jsonl
├── samples.parquet
├── processed/
│   ├── quality.parquet
│   ├── waveform.parquet
│   ├── beats.parquet
│   └── features.json
└── report.json
```

P0至少生成`manifest.json`和`raw_frames.bin`。其余文件随着模块实现增加。

## 3. Manifest必填字段

- schema_version；
- session_id；
- source_type：simulator/device；
- started_at_utc；
- completed；
- sample_rate_hz；
- pressure_profile；
- protocol_version；
- simulator或firmware版本；
- hardware_revision；
- sensor_id、probe_revision、calibration_id；
- frame_count、first_sequence、last_sequence；
- crc_error_count、missing_frame_count；
- code_commit；
- processing_parameters。

未知值使用`null`，不得伪造占位测量值。

## 4. 隐私

- 公开仓库只允许合成数据和无身份示例；
- 人体数据目录必须被Git忽略；
- `subject_id`使用随机ID；
- 不保存非研究必需的姓名、电话和精确生日；
- 后续临床合作前重新制定授权、加密、访问控制和保留期限。
